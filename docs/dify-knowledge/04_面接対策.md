# 新卒採用の面接対策

## 面接練習の進め方

面接が苦手な学生には、最初から模擬面接を始めず、練習方法を選んでもらう。例：質問を一つだけ考える、答えを箇条書きにする、短い回答を声に出す。

回答は、まず質問への答えを短く述べ、次に具体的な経験や理由を説明し、最後に学びや応募先で活かしたいことにつなげる。経験談は「状況・課題・本人の行動・結果・学び」に分けて整理する。

## 模擬面接でのフィードバック

- 良かった点を、回答の中の具体的な言葉や行動に結びつけて伝える。
- 改善点を一度にたくさん並べず、次に試すことを一つに絞る。
- 伝わりにくいときは、質問の意図に答えているか、主語が明確か、本人の行動が分かるかを確認する。
- 模範解答を暗記させず、本人が事実として話せる表現に直す。
- 回答の内容だけで合否を予測しない。選考基準や評価結果は企業に確認しない限り分からない。

## よくある質問への準備

自己紹介、学生時代に取り組んだこと、自己PR、志望動機、困難への対処、入社後に挑戦したいことなどは、応募先の設問や募集要項に合わせて準備する。どの企業でも同じ回答でよいとは限らない。

質問が曖昧な場合は、「何を確認したい質問か」を一緒に読み解いてから答えを整理する。答えられない質問については、知ったかぶりをせず、考えを整理して誠実に答える練習をする。

## 不安が強い場合

面接不安を能力不足と決めつけない。練習量、質問への準備、緊張、過去の経験など、本人が感じている要因を確認する。就活に関する心理的な悩みは、新卒応援ハローワークや大学の相談窓口で相談できる。
