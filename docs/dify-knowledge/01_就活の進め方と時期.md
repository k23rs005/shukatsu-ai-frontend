# 大学生の就職活動：進め方と時期

## この資料の使い方

学生の学年、卒業予定年度、現在の状況、本人が困っていることを確認してから案内する。全員に同じ順番やペースを押しつけず、今できる小さな行動を一つ提案する。

## 基本的な進め方

就職活動は、次の活動を状況に応じて組み合わせる。順番どおりに進んでいないことを責めない。

1. 興味、得意なこと、避けたい働き方を振り返る。
2. 職種や業界について、仕事内容と必要なスキルを調べる。
3. 自分が大切にしたい条件を整理し、企業を比較する。
4. 応募先に合わせて履歴書やエントリーシート（ES）を準備する。
5. 面接で経験や考えを伝える練習をする。
6. 内定後は、求人情報だけでなく個別に示される労働条件を確認する。

何から始めるか分からない学生には、卒業予定年度、使える時間、直近の締切を聞き、10～20分でできる一歩に分解する。例：気になる仕事を一つ選び、仕事内容を一つ調べる。

## 卒業年度別の日程

採用活動の時期は卒業予定年度によって異なり、政府の要請・大学の申合せ・企業の採用方法も確認が必要。年度を確認せずに日程を断定しない。

厚生労働省が掲載する「2027（令和9）年度卒業・修了予定者」の原則的な日程は、広報活動が卒業・修了年度に入る直前の3月1日以降、採用選考活動が卒業・修了年度の6月1日以降、正式な内定が卒業・修了年度の10月1日以降。一定の条件を満たす専門活用型インターンシップ経由の採用には例外がある。

この日程は企業側への要請を含む原則であり、個々の学生に「この日までに内定が必要」と課すものではない。学生の卒業予定年度を聞いたうえで、回答時点の政府・大学の最新情報を確認する。

## 就活が止まっているとき

- 「やる気がない」と決めつけず、何が負担かを聞く。例：失敗への不安、情報の多さ、応募書類、時間、体調。
- 一度に複数の宿題を出さない。
- すぐ応募することを唯一の前進とみなさない。相談する、条件を一つ書く、求人を一件見ることも前進として扱う。
- 強い不安や心身の不調が続くときは、大学の相談窓口や公的な支援窓口を案内する。
