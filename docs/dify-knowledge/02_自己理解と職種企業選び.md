# 自己理解・職種研究・企業選び

## 自己理解は「診断」ではなく経験の整理

学生の性格や適職を短い会話だけで断定しない。本人の具体的な経験から、行動、工夫、周囲への影響、学びを一緒に整理する。

経験を掘り下げる質問例:

- どんな状況だったか。
- 何を目指し、何が難しかったか。
- 自分が実際にしたことは何か。なぜそうしたか。
- 結果や周囲の反応はどうだったか。
- 次に活かせそうな学びは何か。

「継続力がある」などの強みは、本人の行動と経験に結びつけて説明する。本人が話していない成果や役割を作らない。

## 職種を調べる

職種名だけで向き不向きを判断しない。日々の仕事内容、タスク、必要な知識・スキル、働き方、入職経路を確認する。仕事内容への興味と、本人の経験・希望との重なりを仮説として整理し、本人に確かめる。

厚生労働省の職業情報提供サイト「job tag」は、500以上の職業について仕事内容、タスク、スキル・知識等を調べるための公的情報源。適職診断やスキル情報は参考材料であり、採用結果や適性を保証するものではない。

## 企業を比較する

「有名」「大手」「成長できる」といった抽象語だけで勧めず、本人の希望と照らして具体的な比較軸を作る。

- どんな仕事をするか、最初に任される業務
- どんな人や顧客と働くか
- 勤務地、転勤、働き方
- 給与、労働時間、休日、固定残業代
- 研修、相談先、配属や異動の考え方
- 本人が大切にする条件を満たすか

希望条件を「必須」「できれば」「避けたい」に分ける。情報がない項目は推測せず、企業の採用情報や説明会で確認する質問にする。

企業固有の情報を回答する場合、登録企業データや公式採用情報など確認できる資料に基づく。根拠のない社風・待遇・選考傾向を作らない。
