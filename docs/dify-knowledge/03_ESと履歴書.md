# エントリーシート（ES）・履歴書の支援

## 添削の前に確認すること

1. 設問文を正確に確認する。
2. 文字数、提出形式、締切を確認する。
3. 学生本人の経験、役割、行動、結果を聞く。
4. 応募先について本人が確認した事実を聞く。

必要な情報が足りないときは、完成文を先に作らず、足りない情報を一つずつ質問する。

## 文章を組み立てる

自己PRや経験談は、次の流れで整理できる。

- 結論: 何を伝えたいか。
- 状況・課題: いつ、どんな場面で何が課題だったか。
- 行動: 本人が考えて実際に行った工夫。
- 結果: 何が変わったか。数字がなければ観察できた変化を使う。
- 学び・活用: 何を学び、応募先の仕事でどう活かせるか。

志望動機は、本人の関心・経験、応募先の具体的な事業や仕事、入社後に取り組みたいことのつながりを作る。会社名を差し替えただけの文や、会社について確認していない事実を含めない。

## 添削の原則

- 本人の話し方や意図を残し、過度に立派な表現へ書き換えない。
- 成果、役職、数値、理由を創作しない。
- 曖昧な箇所を指摘するときは、本人に確認する質問を示す。
- まず良い点を具体的に伝え、次に最も効果の大きい改善点を一つ示す。
- 文字数制限がある場合、文字数を確認してから案を提示する。未確認なら「文字数は未確認」と伝える。
- 最終文は本人が事実確認し、自分の言葉として納得してから提出するよう促す。

## 履歴書の確認

学校名、資格名、日付などの固有情報は公式名称を確認する。応募先から指定様式や指定ルールがある場合は、それを優先する。履歴書の慣習は応募先・学校の案内で異なることがあるため、一律のルールとして断言しない。

## 公的な作成支援

新卒応援ハローワークでは、ES・履歴書の作成支援や添削を受けられる。AIで整理した案に不安があるときは、大学のキャリアセンターや新卒応援ハローワークで人にも確認してもらう選択肢を案内する。
