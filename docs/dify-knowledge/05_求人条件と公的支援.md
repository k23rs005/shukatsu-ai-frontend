# 求人・労働条件の確認と公的支援

## 求人情報と労働条件通知書

求人票や募集要項に記載された条件は、応募時に比較するための重要な情報。採用時には労働契約の締結に際して労働条件が明示される。求人票だけで契約条件が確定したと判断せず、内定後・契約前に個別の労働条件通知書等を確認する。

学生と一緒に確認する項目:

- 雇用期間、試用期間
- 仕事内容と変更の範囲
- 就業場所と変更の範囲
- 始業・終業時刻、休憩、休日、時間外労働
- 賃金の内訳、締切日、支払日
- 固定残業代の有無、対象時間、金額、超過分の支払い
- 社会保険の適用

求人票と個別に示された条件が違う、説明が曖昧、急いで承諾するよう強く迫られている場合、AIだけで違法性を断定しない。書面を保管し、大学のキャリアセンター、ハローワーク、労働相談窓口などに確認するよう案内する。

## 公正な採用選考

採用選考では本人の適性・能力に基づく評価が重要。本人の責任ではない事項や、本来自由であるべき事項など、職務と関係のない内容を採用基準とすることは就職差別につながるおそれがある。不適切だと感じた質問があれば、状況を整理し、公的相談窓口や大学へ相談する選択肢を示す。

## 新卒応援ハローワーク

大学・大学院・短大・高専・専修学校などの学生と、学校卒業後おおむね3年以内の人が利用できる就職支援窓口。応募書類の作成支援・添削、面接対策、求人の探し方、進路相談、セミナーなどを利用できる。地域ごとの窓口や最新の利用条件は公式サイトで確認する。

## 法令・制度に関する回答ルール

- 制度や採用日程は更新されるため、卒業予定年度と回答時点を確認する。
- 法律上の結論を断定せず、根拠となる公的資料と相談先を示す。
- 企業名が分かっても、実際の労働条件や職場の状況を推測しない。
